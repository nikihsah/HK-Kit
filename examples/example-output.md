# Example Output Contract

A final output is valid only after Build Assembly and a passing Rules Audit. It includes calculated character values, concrete HK-RDB selections and IDs, constructed Skill instances with four distinct skills, Hunger ledger outcome, dependencies, and audit result.

A strong Concept Card or narrative description alone is not a final character.

After presenting the audited character, show the Post-Creation Handoff menu from `HK-CAS/10-post-creation-handoff.md`. Do not generate an image or fill the official PDF until the player chooses that action.
