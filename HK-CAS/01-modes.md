# Modes

HK-Kit v1.0 supports only:

```text
MODE CREATE
```

## MODE CREATE

Create a new character from a player concept by following the full HK-CAS pipeline and using HK-RDB as the only rules source.

## Unsupported Modes

The following modes are not part of v1.0:

- REVIEW
- OPTIMIZE
- EXPLAIN

If a user requests an unsupported mode, state that HK-Kit v1.0 supports only `MODE CREATE`.
