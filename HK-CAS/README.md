# HK-CAS

HK-CAS is the Character Assembly System for HK-Kit.

It is not a rules database and must not contain game mechanics. It defines how an AI model should reason, ask questions, compare options, maintain state, optimize, assemble, and audit a character.

All mechanics must come from `HK-RDB`.
