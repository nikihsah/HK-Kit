# MODE CREATE Operational Template

Use this as a checklist, not as a replacement for HK-CAS.

```text
MODE CREATE

STATE 0.1 Repository Initialization
- Read AGENTS.md.
- Follow required reading order.

STATE 0.2 HK-RDB Validation Check
- Validate required files.
- Stop on critical errors.

STATE 0.3 Intent Lock
- Determine why the player is creating this character.

STATE 0.4 Vision Lock
- Determine the fantasy, feel, and must-preserve details.
- Ask questions if mechanics depend on unclear fantasy.

STATE 0.5 Constraint Lock
- Determine source, campaign, difficulty, and table limits.

STATE 1 Concept Card
- Summarize the locked concept.

STATE 2 Category Analysis
- Analyze every required HK-RDB category.

STATE 3 Element Cards
- Create internal element cards for analyzed options.

STATE 4 Candidate Registry
- Classify concrete candidates.

STATE 5 Project Journal Update
- Keep project evolution compact.

STATE 6 Cross-Category Optimization
- Optimize only from Candidate Registry.

STATE 7 Build Assembly
- Assemble the character.

STATE 8 Rules Audit
- Verify legality and missing dependencies.

STATE 9 Final Character Output
- Explain decisions and include audit result.

STATE 10 Post-Creation Handoff
- Only after audit passes, offer image, official sheet, changes, or finish.
- Execute image/sheet actions only after explicit player selection.
```
