# Audit

A character is not complete before audit.

## Verify

- template legality
- characteristic values
- resource values
- hunger limit
- Hunger Budget Ledger arithmetic, sources, candidate-search completion, and unused-budget explanation
- trait count
- subtrait parent requirements
- load
- path requirements
- skill rank
- complete Skills-category analysis and justification when fewer than three skills are selected
- arts and techniques
- every Secret matches the selected Mystic Path by exact HK-RDB ID
- every Combat Art has a selected Martial Path and satisfies its weapon/condition requirements
- charms and marks
- equipment
- combat loop
- missing fields
- unresolved dependencies
- full mechanical selection and calculation rather than Concept Card-only completion
- official HK-RDB name and ID beside every renamed or reflavored ability
- confirmation that reflavoring changed no mechanics

## Output

The audit must report:

- pass/fail status;
- checked categories;
- blocking issues;
- warnings;
- source references for major mechanical decisions.

If any critical issue remains, do not present the character as complete.

A polished narrative or strong Concept Card cannot pass the audit without a complete mechanical build and calculated character sheet.
