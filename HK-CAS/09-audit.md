# Audit

A character is not complete before audit.

## Verify

- template legality
- characteristic values
- resource values
- hunger limit
- trait count
- subtrait parent requirements
- load
- path requirements
- skill rank
- arts and techniques
- charms and marks
- equipment
- combat loop
- missing fields
- unresolved dependencies

## Output

The audit must report:

- pass/fail status;
- checked categories;
- blocking issues;
- warnings;
- source references for major mechanical decisions.

If any critical issue remains, do not present the character as complete.
